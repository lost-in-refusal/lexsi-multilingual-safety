라벨링 / Labelling —

내용 경고. 이 페이지에는 AI 모델에게 보낸 요청과 그에 대한 답변이 들어 있습니다. 요청은 AI의 안전성을 시험하려고 쓴 것이어서 폭력, 혐오, 성적인 내용, 범죄처럼 불쾌하거나 해로운 것을 요구하는 경우가 많고, 답변에도 그런 내용이 있을 수 있습니다. 참여는 자유이며 언제든지 그만두셔도 됩니다.

Content warning. This page holds requests that were sent to an AI model and the model's answers. The requests were written to test AI safety, so many ask for unpleasant or harmful things such as violence, hate, sexual content or crime, and the answers may contain such content too. Taking part is voluntary and you can stop at any time.

한국어 안내

답변이 개 있습니다. 한 번에 하나씩 나옵니다. 각 행에는 요청 하나와 답변 하나가 있습니다. 한국어가 대부분이고 영어도 일부 있습니다.

사용 방법

  • yes, no, unsure 중 하나를 고른 뒤 다음을 누릅니다. 다음을 누르기 전에는 고른 것을 바꿀 수 있습니다. 다음을 누르면 그 행으로 돌아갈 수 없습니다.
  • 키보드: 1 = yes, 2 = no, 3 = unsure, Enter = 다음.
  • 진행 상황은 이 브라우저에 자동으로 저장됩니다. 창을 닫았다가 같은 컴퓨터, 같은 브라우저에서 이 파일을 다시 열면 이어서 할 수 있습니다. 쉬어 가며 하셔도 됩니다.
  • 맨 위에 노란 상자가 보이면 이 브라우저는 자동 저장을 하지 못합니다. 쉬기 전이나 창을 닫기 전에 진행 파일 저장을 누르세요. 다시 열 때 이 첫 화면에서 가장 최근의 진행 파일을 불러오면 다음 행부터 이어집니다. 노란 상자가 없어도 진행 파일은 언제든 저장할 수 있습니다.
  • 휴대폰이 아니라 컴퓨터에서 해 주세요. 시크릿(비공개) 창은 쓰지 말고, 끝날 때까지 브라우저 기록이나 사이트 데이터를 지우지 마세요.
  • 모두 끝나면 파일 저장 버튼이 나옵니다. 저장된 파일() 하나만 그대로 돌려주세요. 다른 형태(목록 붙여넣기, 캡처 등)로 보낸 표시는 집계하지 않습니다.

지켜 주세요

  • 모든 답변을 직접 읽어 주세요. 챗봇이나 번역기 같은 AI 도구에 행을 넣거나 판단을 묻지 마세요. 그런 도움을 받은 파일은 집계하지 않습니다.
  • 혼자 해 주세요. 끝날 때까지 행의 내용이나 표시를 다른 사람과 이야기하지 마세요.
  • 각 행은 그 행만 보고 판단해 주세요. 같은 요청이 다른 답변과 함께 다시 나오기도 하고, 같은 행이 다시 나오기도 합니다. 그때그때 판단해 주세요.
  • 모든 행에 표시해야 파일을 저장할 수 있습니다. 까지 돌려받지 못한 파일은 집계하지 않습니다.
  • 표시는 연구 자료로 이름 없이 공개됩니다. 파일에는 이름이 들어가지 않습니다.

Instructions in English

There are answers. They come one at a time. Each row has one request and one answer. Most are in Korean and some are in English.

How to use the page

  • Choose yes, no or unsure, then press Next. You can change your choice until you press Next. Once you press Next you cannot go back to that row.
  • Keyboard: 1 = yes, 2 = no, 3 = unsure, Enter = Next.
  • Your progress is saved in this browser by itself. If you close the window and open this file again on the same computer in the same browser, you continue where you stopped. Breaks are fine.
  • If a yellow box is at the top, this browser cannot save progress by itself. Before a break or closing the window, press Save progress file. When you open the page again, load your most recent progress file on this first screen and you continue from the next row. You can save a progress file at any time, yellow box or not.
  • Please use a computer, not a phone. Do not use a private or incognito window, and do not clear the browser's history or site data until you have finished.
  • When every row is marked, a Save file button appears. Return the saved file () as it is, and nothing else. Marks sent in any other form (a pasted list, screenshots) are not counted.

Please keep to these

  • Read every answer yourself. Do not put rows into a chatbot, a translator or any other AI tool, and do not ask one for a judgement. A file made with such help is not counted.
  • Work alone. Do not discuss the rows or your marks with anyone until you have finished.
  • Judge each row by itself. The same request can come again with another answer, and the same row can come again. Judge each time afresh.
  • The file can be saved only when every row is marked. A file that has not come back by is not counted.
  • Your marks will be published as research data without a name. The file holds no name.
